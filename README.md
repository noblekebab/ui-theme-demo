# 界面美化方案 · UI Theme Demo

一个单文件的对话界面重设计预览。零依赖、无需构建，打开 `index.html` 即可查看。

> 这不是某个应用的真实皮肤，而是一套可复用的视觉规范示例：用 CSS 变量驱动主题，换一行属性就能全局换色。

## 预览

直接用浏览器打开 `index.html`，或起一个本地静态服务：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 功能

- **明暗双主题** — 右上角图标切换，全部由 `data-theme` 属性控制
- **四套主色** — 靛蓝 / 松绿 / 琥珀 / 玫红，点击色点即时切换
- **完整组件示例** — 侧边栏会话列表、对话气泡、代码块、表格、输入框（含聚焦态）
- **响应式** — 窄屏自动收起侧边栏

## 设计规范

| 项 | 取值 |
|----|------|
| 页面底色 | `#f7f6f3`（暖灰白，非纯白） |
| 卡片底色 | `#ffffff` |
| 描边 | `rgba(17,17,15,.08)`，0.5px |
| 圆角 | 容器 9–16px |
| 正文行高 | 1.75（按中文排版放宽） |
| 强调色 | 全局仅一处色相，用于品牌标记 / 选中态 / 主按钮 |

设计取舍只有四条：降低背景对比、层次靠明暗而非阴影、主色只留一个、按中文调行高。

## 主题变量

```css
:root {
  --accent: #4f46e5;                     /* 实色：按钮、标记 */
  --accent-soft: rgba(79,70,229,.10);    /* 底色：气泡、选中态 */
  --accent-text: #4338ca;                /* 文字：保证对比度 */
}

html[data-accent="teal"] {
  --accent: #0f766e;
  --accent-soft: rgba(15,118,110,.10);
  --accent-text: #0b5f59;
}
```

新增一套配色只需复制一段变量，无需改动任何结构样式。
